# 观我生 · 样书

在线翻读：https://alanhuang116.github.io/guanwosheng-samples/

《观我生》是「时藏」里为一张八字写的一函书：本册讲这个人，岁册讲这一年。这里摆着第七版的三函样书，用的就是时藏线上那个阅读器：竖排，书脊在右，手机上一次一页，电脑上摊开两页。

- 三张盘都是虚构的测试盘，不是真人：甲盘（乾造，一九八九年亥月），乙盘（坤造，一九九五年未月），丙盘（坤造，一九七二年卯月，时辰不详）。
- 书由 AI 撰写（DeepSeek），排盘、十神、流年由程序算定，引文对原书核对过。内容是按传统命理写的解读，只说倾向，不断结局，不替人做医疗、投资、法律决定。

## 怎么翻

- **翻页**：竖排的书往左翻，点书的左边、往右拨是下一页；电脑上也可以用滚轮、方向键、空格。
- **目录笺**：点书顶的章名或「目」，每一章、每张图版、每步大运、每个月都能直接翻到，也能在本册和岁册之间换。
- **叶尺**：按住书底的尺拖动，书跟着翻，松手就停；跳走以后底部留着「↩ 回第几叶」。
- **圈点与依据**：按住一段，朱笔圈下来；点段末的「据」，看这段依据盘上哪几个字；点图版上的字，看它的释名。

网址可以直接指到某一册：`#a-ben` 是甲盘本册，`#b-sui` 是乙盘岁册，依此类推。圈点和读到哪只记在各自的设备上。

这个站是用时藏仓库里的 `tools/samples/build.mjs` 打出来的静态文件（`assets/` 里是脚本、样式和字体），不连服务器。
